## ✨ Key Features
- **🍱 Autonomous Dining Radar**: Live daily/weekly mess menus with automated scheduled meal alerts (Breakfast, Lunch, Snacks, Dinner).
- **🚨 Instant Complaint Dispatch**: Fast grievance ticketing with live caretaker/warden workflow, photo attachments, and status tracking.
- **🎓 Academics & Exam Radar**: Odd semester timetable, live lecture status, 5th semester syllabus, and gazetted holiday calendars.
- **👑 Granular RBAC Administration**: Multi-tier hierarchy (Student, Caretaker, Warden, Superintendent, Super Admin) with scoped Sub-Admin delegation.
- **📲 Live OTA (Over-The-Air) Hotfixes**: Instant live update engine delivering zero-download feature rollouts directly to devices.
- **🎨 Warm Linen & Espresso Aesthetic**: Tactile design system with seamless support for light, dark, and room pod ambient themes.

---

## 🛠️ Technology Stack
- **Frontend**: React 19, Vite, Tailwind CSS, GSAP, Lucide Icons
- **Mobile Native**: Capacitor 6 (Android & Cross-Platform)
- **Backend**: Node.js, Express.js (Dockerized)
- **Cloud Infrastructure**: AWS EC2, Cloudflare CDN/Workers, DuckDNS SSL (Let's Encrypt)
- **Database**: MongoDB Atlas with Mongoose ODM
- **Real-Time & Notifications**: Firebase Cloud Messaging (FCM), WebSockets, Web Push
